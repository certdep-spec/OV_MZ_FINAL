# CertifyPro v3.0: Руководство Системного Администратора (Admin Guide)

**Версия:** 3.0
**Цель документа:** Описание процесса развертывания, настройки и расширения системы для системных администраторов.

---

## 📦 Развертывание Проекта

CertifyPro v3.0 поставляется в виде автономного исполняемого файла (`.exe`), скомпилированного через PyInstaller. Это минимизирует зависимость от окружения Python на целевой машине.

**Шаги развертывания:**
1.  Распакуйте содержимое папки `CertifyPro_v3.0`.
2.  Убедитесь, что в директории присутствуют следующие ключевые компоненты:
    *   `certifypro.exe`: Основной исполняемый файл приложения.
    *   `resources/profiles.yaml`: Файл конфигурации всех поддерживаемых клиентов.
    *   `projects/*/data/`: Директория для хранения локальных баз данных SQLite.
    *   `resources/templates/`: Директория, содержащая DOCX шаблоны документов.

**Запуск:** Запуск осуществляется двойным кликом по `certifypro.exe`. При первом запуске приложение автоматически проверит наличие и валидность конфигурации в `profiles.yaml` при помощи встроенного `ClientManager`.

## 📂 Структура Папок (Directory Structure)

| Путь | Назначение | Описание |
| :--- | :--- | :--- |
| `resources/profiles.yaml` | **Конфигурация** | Центральный источник истины для всех клиентских профилей. Определяет подключение и параметры каждого клиента. |
| `projects/*/data/` | **Данные (DB)** | Хранилище локальных баз данных SQLite, связанных с конкретными клиентами. Ссылки на них указываются в профиле. |
| `resources/templates/` | **Шаблоны** | Содержит все DOCX шаблоны документов. Именование должно соответствовать логике генерации. |
| `certifypro.exe` | **Исполняемый файл** | Основное приложение. |

## ➕ Добавление Нового Клиента (Onboarding New Client)

### Автоматический способ (рекомендуется, v3.1+)

При добавлении нового клиента через GUI лаунчера вся инфраструктура создаётся автоматически:

1.  **Откройте лаунчер** и нажмите **"⚙️ Керувати заявниками"**
2.  Нажмите **"➕ Додати"** и заполните форму:
    *   Назва підприємства
    *   Адреса
    *   ЄДРПОУ (8 или 10 цифр)
    *   Керівник
    *   **Папка проекту** — уникальное имя (например, `НОВИЙ_КЛІЄНТ`)
3.  Нажмите **"✅ Зберегти"**

Система автоматически:
*   ✅ Создаст папку проекта: `<PROJECT_ROOT>/<papka_proektu>/data/`
*   ✅ Создаст подпапку `Documents/` для сгенерированных документов
*   ✅ Инициализирует пустую БД `certify.db` с полной схемой (6 таблиц)
*   ✅ Добавит запись в `profiles.yaml` с параметрами по умолчанию
*   ✅ Выполнит откат при ошибке (удалит запись из реестра)

**Результат:** Клиент сразу доступен в лаунчере и готов к работе.

> **Примечание:** `papka_proektu` транслитерируется латиницей для `client_id` в `profiles.yaml`. Например, "НОВИЙ_КЛІЄНТ" → `novyj_klient`.

### Ручной способ (для продвинутых пользователей)

Если автоматическое создание недоступно или требуется кастомная настройка:

### Шаг 1: Обновление `profiles.yaml`
Откройте `resources/profiles.yaml` и добавьте новый блок для клиента. **Обязательно** укажите уникальный `client_id`, соответствующий суффиксу, который будет использоваться в генерации шаблона и базе данных.

```yaml
# Пример добавления нового клиента "НОВИЙ_КЛІЄНТ"
clients:
  novyj_klient:
    name: "НОВИЙ_КЛІЄНТ"
    display_name: "ТОВ «НОВИЙ КЛІЄНТ»"
    template_suffix: "_Н"
    launcher_mapping: "НОВИЙ_КЛІЄНТ"
    data_dir: "data/НОВИЙ_КЛІЄНТ"
    company:
      name: "ТОВ «НОВИЙ КЛІЄНТ»"
      code: "12345678"
      director: "Иванов И.И."
    features:
      import_product: false
      ugoda_templates: 1
    description: "Новий клієнт (ручне додавання)"
```

### Шаг 2: Создание инфраструктуры
1.  **Создайте папку:** `<PROJECT_ROOT>/<papka_proektu>/data/`
2.  **Инициализируйте БД:** Выполните `python client_provisioner.py` или используйте `db_schema.sql` напрямую через `sqlite3 certify.db < db_schema.sql`
3.  **Шаблоны:** Поместите DOCX шаблоны в `resources/templates/` с суффиксом клиента (например, `1_Заявка_бланк_Н.docx`)

После выполнения этих шагов перезапустите приложение, чтобы `ClientManager` обнаружил и активировал новый профиль в окне лаунчера.
