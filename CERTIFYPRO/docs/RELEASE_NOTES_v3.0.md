# CertifyPro v3.0 Release Notes

**Version:** 3.0.0
**Release Date:** 2026-04-12
**Status:** Stable Production Release

---

## ✨ Обзор Релиза

Версия 3.0 представляет собой фундаментальный рефакторинг и объединение всех функциональных возможностей, ранее разделенных между форками Athena и Johnson. Мы перешли от устаревшей архитектуры к современной, унифицированной, многоклиентской системе с единой кодовой базой. Это обеспечивает стабильность, расширяемость и простоту поддержки в будущем.

**Ключевые улучшения:**
*   **Единая Кодовая База (Single Source of Truth):** Устранена дублирующаяся логика и несовместимости между старыми ветками.
*   **Улучшенное Управление Конфигурацией:** Внедрена строгая валидация конфигурации клиентов через YAML-файлы, что минимизирует ошибки при настройке.
*   **Интерфейс Пользователя (UI/UX):** Добавлен централизованный экран выбора клиента в лаунчере для быстрой передислокации между профилями.

## 🚀 Основные Нововведения и Изменения (v2.0 $\rightarrow$ v3.0)

### 🌐 Архитектурный Сдвиг
*   **Мультиклиентская Поддержка:** Система теперь управляет несколькими независимыми клиентскими конфигурациями из одного экземпляра приложения, используя `ClientManager`.
*   **Конфигурация через YAML:** Все настройки профилей (включая параметры генерации и подключения) теперь централизованно определяются в `profiles.yaml` с использованием строгой валидации данных (`dataclasses`).

### 📄 Генерация Документов (Strategy Pattern Implementation)
*   Внедрена паттерн **Strategy** для генерации документов. Вместо жестко закодированных путей, система динамически подгружает соответствующий генератор шаблона на основе суффикса клиента (например, `_А` или `_Д`).
*   Базовый класс `BasePartyDocumentGenerator` стандартизирует процесс создания всех типов отчетов.

### 🛠️ Улучшения Функционала Клиентов
*   **Клиент Джонсон:** Добавлена специализированная функция `import_product`, позволяющая импортировать продуктовые каталоги напрямую из внешних источников, минуя ручной ввод.
*   **Общее:** Значительное устранение технического долга (Tech Debt) в модулях обработки данных и инициализации сессий.

## 🐛 Исправления Ошибок (Bug Fixes)
*   Исправлена проблема с некорректным закрытием соединений к базе данных при аварийном завершении работы приложения.
*   Улучшена обработка краевых случаев, когда в `profiles.yaml` отсутствует обязательное поле для определенного клиента.

## ⚙️ Как Обновиться (Deployment Notes)
Пользователям рекомендуется удалить старые версии и установить CertifyPro v3.0, собранную через PyInstaller `.exe`, чтобы гарантировать использование унифицированной кодовой базы.
