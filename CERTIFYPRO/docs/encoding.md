# Кодировка (Windows / Linux / macOS)

Проект полностью работает в UTF-8:

- Все текстовые файлы открываются с `encoding='utf-8'`.
- При старте приложения выполняется `sys.stdout.reconfigure(encoding='utf-8')` и аналогично для `sys.stderr`.
- Переменная окружения `PYTHONIOENCODING` установлена в `utf-8` для всех дочерних процессов.
- `subprocess.Popen` / `subprocess.run` вызываются с явным `encoding='utf-8'`.

**Никакой транслитерации или замены кириллицы на латиницу в именах папок (ДЖОНСОН, АФІНА) или БД не требуется.** Любой новый код должен строго следовать этому стандарту.
