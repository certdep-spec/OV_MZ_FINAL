# Замітки до релізу v3.0.0

**Дата:** 12 квітня 2026  
**Версія:** 3.0.0 (мультиклієнтська)  
**Тип релізу:** Major (зворотна несумісність конфігурації)

---

## 📋 Огляд

CertifyPro v3.0 — це масштабне оновлення архітектури, яке додає підтримку декількох клієнтів із єдиною кодовою базою. Система автоматично вибирає правильні шаблони, базу даних та налаштування на основі профілю клієнта.

---

## 🆕 Що нового

### Мультиклієнтська архітектура
- Профілі клієнтів у `profiles.yaml` — жодного захардкодженого клієнта
- Автоматичний вибір шаблонів (`_А` для АФІНА, `_Д` для ДЖОНСОН)
- Окрема БД для кожного клієнта
- Індикатор клієнта у куті кожного вікна

### Додавання нового клієнта без правки коду
1. Додати профіль в `profiles.yaml`
2. Створити папку `data/` з порожньою `certify.db`
3. Створити шаблони `*_Н.docx`
4. Додати заявника через лаунчер

**Раніше:** потрібно було редагувати `launcher.py`, `config.py`, додавати нові гілки `if/else`.

### Портативний .exe
- БД вбудовані в .exe
- При першому запуску автоматично розгортаються бази даних
- Працює з флешки / будь-якої папки без встановлення Python

### Покращення коду
- Видалено ~800 рядків дублювання
- Створено 5 нових модулів (теги, геометрія, реєстрація, додатки, базовий генератор)
- Додано E2E-тест переключення контексту
- Видалено мертвий код (`ProtocolGenerator`)

## ⚠️ Відомі проблеми

| Проблема | Вплив | Обхідний шлях |
|---|---|---|
| Глобальні змінні в `config.py` все ще оновлюються | Технічний борг | Використовуйте `get_client_config()` замість прямого доступу |
| `ZayavkaGenerator` все ще має 129 строк | Можна розділити далі | Не блокує роботу |
| Немає DatePicker у діалозі дат | Ручне введення дат | Вводьте у форматі `дд.мм.рррр` |

## 🔄 Оновлення з v2.x

### ⚡ Breaking Changes
- `profiles.yaml` — новий обов'язковий файл конфігурації
- Шляхи до БД стали відносними (`data/АФІНА` замість `C:/FINAL/АФІНА/data`)
- `DocumentContextBuilder` перейменовано в `DocumentDataService`

### 📋 Міграція
1. **Не змінюйте** папку `data/` — вона автоматично підхоплюється
2. **Не змінюйте** папку `templates/` — шаблони сумісні
3. **Перезапустіть** .exe — бази даних розгорнуться автоматично
