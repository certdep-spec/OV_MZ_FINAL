# Політика версіонування

CertifyPro дотримується [Semantic Versioning 2.0.0](https://semver.org/lang/ru/).

## Формат версії

```
МАЖОРНА.МІНОРНА.ПАТЧ
  X      .  Y    .  Z
```

| Частина | Коли збільшується | Приклад |
|---|---|---|
| **МАЖОРНА (X)** | Зворотна несумісність (breaking changes) | `2.0.0` → `3.0.0` |
| **МІНОРНА (Y)** | Нова функціональність (зворотна сумісність) | `3.0.0` → `3.1.0` |
| **ПАТЧ (Z)** | Виправлення багів | `3.1.0` → `3.1.1` |

## Теги Git

Кожен реліз має відповідний Git-тег:

```bash
git tag -a v3.0.0 -m "Реліз v3.0.0 — Мультиклієнтська архітектура"
git push origin v3.0.0
```

---

## Перед релізом — чеклист

- [ ] Всі тести проходять (`python tests\run_tests.py`)
- [ ] E2E-тест проходить (`python tests\test_e2e_client_switching.py`)
- [ ] CHANGELOG.md оновлено
- [ ] Версія в `config.py` оновлена (`VERSION = "X.Y.Z"`)
- [ ] Версія в `pyproject.toml` оновлена
- [ ] `.exe` зібрано і протестовано
- [ ] RELEASE_NOTES.md створено
- [ ] Git-тег створено
- [ ] README.md актуалізовано

## Lifecycle версій

| Стадія | Опис |
|---|---|
| `0.x.x` | Початкова розробка (API нестабільний) |
| `1.x.x` | Перший стабільний реліз |
| `2.x.x` | Оптимізація архітектури |
| `3.x.x` | **Поточна** — Мультиклієнтська |
| `4.x.x` | Майбутня — Web-інтерфейс? |
