## 🐛 ВИРІШЕНІ ПРОБЛЕМИ

### Проблема 1: Дані "зникли"
**Симптом:** Нова система створила пусті БД в CERTIFYPRO/projects/
**Рішення:** В profiles.yaml вказано absolute paths до СТАРИХ БД:
- `C:/FINAL/АФІНА/data`
- `C:/FINAL/ДЖОНСОН/data`

### Проблема 2: Config ініціалізувався до вибору клієнта
**Симптом:** DEFAULT_COMPANY був None або дефолтним ДЖОНСОН
**Рішення:** 
- config.py тепер не встановлює DEFAULT_COMPANY при імпорті
- init_client_config() викликається ПЕРЕД іншими імпортами

### Проблема 3: Запуск розбився на два
**Симптом:** Треба було пам'ятати `python main.py afina`
**Рішення:** main.py тепер показує GUI екран вибору клієнта

## 📝 АРХІТЕКТУРНІ РІШЕННЯ

### Чому дані не переміщені?
1. Безпека - старі дані залишаються незмінними
2. Можливість відкату - якщо щось не працює, можна використовувати стару систему
3. Поетапна міграція - спочатку перевірка, потім перенесення

### Як працює вибір шаблонів:
```python
# В коді генератора:
from documents.template_resolver import build_template_name

def get_template_name(self):
    return build_template_name("1_Заявка_бланк")
    # Для АФІНА поверне: "1_Заявка_бланк_А.docx"
    # Для ДЖОНСОН поверне: "1_Заявка_бланк_Д.docx"
```

### Як працюють feature flags:
```python
from config import has_feature

if has_feature("import_product"):
    # Код для імпортної продукції (тільки ДЖОНСОН)
    is_import = detect_import_type()
else:
    # АФІНА - завжди вітчизняна
    is_import = False
```
